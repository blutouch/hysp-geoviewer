# Changelog

All notable changes to HYSP GeoViewer will be documented here.

---

## [0.1.0-beta1] - 2026-07-16

### Added

- Initial private beta release
- Interactive map viewer
- IMAGE layer support
- OBS layer support
- Project manager
- Archive browser
- Case browser
- External data loading
- Bounding-box selection
- Time-series generation
- Scatter plots
- Figure capture
- Multiple color tables
- Contour visualization
- Automatic configuration management

### Known Issues

- User interface is still evolving.
- Configuration format may change.
- Some data formats require additional testing.
- Documentation is incomplete.

---

Future releases will summarize new features, bug fixes, and interface changes.
